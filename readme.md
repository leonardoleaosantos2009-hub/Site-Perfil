Cada aluno deve criar o arquivo style.css e cumprir as seguintes missões de estilo:

O Fundo (Background):
Mude o fundo da página inteira (body) para uma cor bonita, um tom pastel ou até um degradê (gradient).

Centralize o cartão de perfil no meio da tela usando Flexbox (display: flex; justify-content: center; align-items: center; height: 100vh;).

O Cartão de Perfil (.card-perfil):
Dê uma cor de fundo branca ou escura para o cartão.

Adicione uma largura fixa (ex: 350px) e cantos arredondados (border-radius).

Coloque um espaçamento interno (padding) caprichado e uma sombra suave (box-shadow) para dar profundidade.

A Foto de Perfil (.foto-perfil):
Deixe a foto redonda (dica: border-radius: 50%).
Adicione uma borda colorida ao redor dela.

Tipografia e Cores:
Troque a fonte padrão por uma do Google Fonts (ex: Poppins ou Inter).
Estilize o nome, o cargo e a bio alterando cores, tamanhos de fonte (font-size) e espaçamentos (margin).

Os Botões (.btn):
Remova o sublinhado feio dos links (text-decoration: none).
Dê formato de botão com padding, cor de fundo e cantos arredondados.
Desafio extra: Faça a cor do botão mudar quando o mouse passar por cima (:hover).
